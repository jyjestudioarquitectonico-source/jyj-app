Conectar Base de Datos

Para sincronizar datos entre todos los dispositivos en tiempo real, configura Firebase (gratis).

1
Ve a console.firebase.google.com e inicia sesion con Google
2
Clic en "Crear un proyecto" → nombre: jyj-app → desactiva Google Analytics → Crear proyecto
3
En el menu lateral: Compilacion → Firestore Database → Crear base de datos → Modo de prueba → Listo
4
Vuelve al inicio del proyecto → icono </> (Web) → nombre: jyj-web → Registrar app
5
Copia el objeto firebaseConfig que aparece y pegalo abajo
Configuracion invalida. Verifica que hayas copiado todo el objeto correctamente.
